## 2026-08-16 · v2.0 落地

### 定位与方向
- 按 PRD 定位：独立开发的 MVP，用于测试开发 / AI 测试方向求职展示。
- 明确的核心诉求：不要“传统前后端调一个 AI API”，而是真实可量化的多智能体协作
  （评审对抗、跨源关联、LangGraph 真编排），并辅以 AI 测试方法论（A/B、回归护栏）。

### 容量能力（A → D → B → C 顺序）
1. **A 对抗协作评审**
   - `src/agents/reviewer.py`：独立 `ReviewerAgent`（规则检查 + 可选 LLM 语义复核）+ `CoordinatorAgent`
     （依据反馈修复 → 复评 → 收敛）。
   - `src/models/review.py`：`ReviewRecord`；`src/storage/db.py` 增加 `ReviewORM` / `save_review` / `count_reviews` / `list_reviews`。
   - `ThreatIntelligence` 扩展 `review_*` 元数据；`workflow` 接入每条 item 的评审并持久化。
   - 指标口径：`review_flagged = 复评轮数 >= 2`、`review_resolved_fixes = 修复问题数`、`review_residual = 修复后仍未通过`。

2. **D 运行时用评估结果**
   - `src/evaluation/runtime.py`：`data/runtime_prompt.json` 存部署版本；`load_active_version` / `save_active_version`。
   - `src/evaluation/regression.py`：回归护栏，基线取 v1.2 指标（acc 0.8 / recall 0.6 / f1 0.69 / avg_conf 0.63）。
   - `src/agents/analyzer.py`：`_version` 优先读取 `runtime_prompt.json`（部署 v1.3）。
   - `scripts/run_ab_test.py --deploy`：A/B 胜利方可一键部署。

3. **B 跨源关联**
   - `src/agents/correlator.py`：按共享 IoC（IP/域名/URL/Hash）union-find 聚类；独立来源数 >= 2 判定
     corroborated 并 confidence +0.03（封顶 1.0）；`key_indicators` 保原始拼写、去重小写归组。
   - `src/models/event.py`：`ThreatEvent`；`db.py` 增加 `ThreatEventORM` / `save_event` / `count_events` / `list_events`。
   - DemoSource 样本改为 11 个独立来源名（`demo:vendor-a` 等），保证跨源可印证。
   - `workflow` Step 4 Correlate；Dashboard 总览页展示关联事件表。

4. **C LangGraph StateGraph 编排**
   - 安装 langgraph 1.2.x（清华镜像）；`src/graph/workflow.py` 重构为 StateGraph：
     五节点 `collect → analyze → validate → correlate → report` + 条件边（`_route_after_correlate` 决定是否走 report）。
   - 节点函数以 `_WorkflowState` dict 通信（result + raw_items + analyzed_items + enable 开关 + limit）。
   - `run()` 有 LangGraph 走 `graph.invoke(state)`，否则线性回退同一批节点。
   - 验证：24 用例全绿；日志可见 `=== Graph Node: X ===` 状态机调度。

## 2026-08-20 · v2.1.0 多领域专题监测 + 合规暗网源

### 定位
把单一卫星域的演示扩展为**多领域通用监测**（卫星/航天、勒索软件、APT、供应链、IoT 僵尸网络），
并落地「合规的暗网监测能力」：不做 Tor 爬虫，只做白名单 + 代理隔离 + 关键词过滤 + 默认关闭的监测。

### 功能增量（三层方案）
1. **LocalDatasetSource**（`src/sources/local_dataset_source.py` + `data/dark_dataset/*.json`）
   - 6 条**合成标注样本**（`sample: true`，IP 全为 RFC5737 保留段），覆盖 5 域，来源分层 4 dark / 2 clearnet；
   - 离线可复现：不依赖 Tor / SOCKS / 网络，业务即可演示「多领域 + 明暗网分级」。
2. **DarkWebSource**（`src/sources/dark_web_source.py`）合规限域监测
   - 默认 `enabled: false`；仅抓显式**白名单** URL（绝不自动发现）；强制显式 SOCKS5 代理且 **fail-closed**；
   - 关键词过滤 + 正文截断（`max_capture_chars`）；全程可审计日志（启用/代理/过滤/抓取每条决策）。
3. **DomainMonitorAgent**（`src/agents/monitor.py` + `src/models/metric.py` + `domain_metrics` 表）
   - 多域关键词切片统计：每域 matched_items / total_sources / dark_sources 持久化；
   - workflow 新增 Monitor 节点：`collect → monitor → analyze → validate → correlate → report`（LangGraph + 线性双路径）。

### Dashboard
- 新增「专题监测」页：逐域指标卡 + 明细表 + 历史趋势折线图；
- 情报列表新增「来源域」列（🌑 暗网 / ☀️ 明网）。
